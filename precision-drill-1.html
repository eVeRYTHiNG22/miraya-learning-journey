Read it. Turn it. Finish it.

Thirteen one-mark questions across Maths, Physics and Chemistry. The content is deliberately low-difficulty — the maths and science here are all things you have already done. Marking
Fully automatic
  • Answer all 13 questions. Each is worth exactly 1 mark, and every answer is a number.
  • The subject changes from question to question — read each one from scratch. That switch is part of the exercise.
  • Marking is all-or-nothing and automatic. There is no method mark and nothing to tick yourself, so an answer that is right except for the direction of a fraction or the last keystroke scores zero — exactly as a wrong answer would.
  • Where a question prints an instruction (“to the nearest hundred”, “state”, “how much was taken off”), that instruction is the question. Q3’s rounding instruction is marked exactly; elsewhere a correctly-worked value is accepted whether or not you rounded it.
  • Type just the number — the unit is already printed beside the box. Write it as an ordinary decimal (0.05), not in standard form.
  • In Timed exam mode a 12-minute countdown runs; the drill locks and marks itself when you submit or time runs out.
  • After marking, every question opens up a worked answer that names the specific slip the question was built to catch. Read those even for the ones you got right.
