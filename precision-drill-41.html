Marking

  • Answer all 13 questions. Each is worth exactly 1 mark. Q1 is multiple choice; the other twelve each want a number typed into the box.
  • Every question is Physics, and the topic keeps changing as you go — motion, forces, measurement, waves, sound, light and energy: this drill is the mixed review of the batch. Read each one from scratch; that switch is part of the exercise.
  • Most questions carry a diagram. Everything the diagram shows — an arrow’s direction, which angle is marked, which length is which — is part of the question. Name what each labelled thing is before you look at what is being asked for.
  • Marking is all-or-nothing and automatic. There is no method mark and nothing to tick yourself, so an answer that is right except for the direction of a fraction or the last keystroke scores zero — exactly as a wrong answer would.
  • Where a question prints an instruction (“to the nearest whole number”, “in cm3”, “as a decimal”), that instruction is the question. Q10’s rounding instruction is marked exactly; elsewhere a correctly-worked value is accepted whether or not you rounded it.
  • On Q2–Q13, type just the number — the unit is printed beside the box wherever the quantity has one. Write it as an ordinary decimal (0.05), not in standard form.
  • In Timed exam mode a 15-minute countdown runs; the drill locks and marks itself when you submit or time runs out.
  • After marking, every question opens up a worked answer that names the specific slip the question was built to catch. Read those even for the ones you got right.
