Precision Drill 6
Read it. Turn it. Finish it.

Thirteen one-mark questions across Maths, Physics and Chemistry. The content is deliberately low-difficulty — the maths and science here are all things you have already done. What each question tests is whether you read the demand exactly, turned the fraction the right way up, and carried the chain all the way to the end. This one re-tests all three families — direction, reading the demand, and finishing — in contexts none of the first five drills used. Half of its questions have a size check built in: an answer that is impossible if you picture what it means. Every question uses numbers and a context that have not appeared on an earlier drill; several deliberately re-run a mechanism from Drills 1 and 2, because the mechanisms are the point.

Marking
Fully automatic
  • Answer all 13 questions. Each is worth exactly 1 mark. Q1 is multiple choice; the other twelve each want a number typed into the box.
  • The subject changes from question to question — read each one from scratch. That switch is part of the exercise.
  • Marking is all-or-nothing and automatic. There is no method mark and nothing to tick yourself, so an answer that is right except for the direction of a fraction or the last keystroke scores zero — exactly as a wrong answer would.
  • Where a question prints an instruction — a rounding, a unit, “as a decimal”, or a word naming which quantity is wanted — that instruction is the question. Q8’s rounding instruction is marked exactly; elsewhere your value is accepted at the precision the question asks for, or finer.
  • On Q2–Q13, type just the number — the unit is already printed beside the box. Write it as an ordinary decimal (0.05), not in standard form.
  • In Timed exam mode a 12-minute countdown runs; the drill locks and marks itself when you submit or time runs out.
  • After marking, every question opens up a worked answer that names the specific slip the question was built to catch. Read those even for the ones you got right.
